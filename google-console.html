Google Console setup checklist

  1. Create or select the GNAI TV project in Google Cloud Console.
  2. Enable only YouTube Data API v3.
  3. Create an API key restricted to that API.
  4. Copy the public YouTube channel ID that starts with UC.
  5. Store both values in Cloudflare Production variables.
  6. Do not commit or paste either value into the repository, issues, or pull requests.

Deployment reminder

After updating Cloudflare variables, redeploy the Pages project and verify /api/health plus /api/youtube-uploads.
